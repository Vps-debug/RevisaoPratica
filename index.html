🏗️Módulo 1 — Modelos e Banco de Dados5 questões

O material apresenta modelos de desenvolvimento e conceitos básicos de banco de dados.

Modelo Incremental

É apresentado como adequado para aplicações Web por ser flexível, permitir mudanças entre versões e facilitar testes e gerenciamento de riscos.

Banco de dados

Local onde informações podem ser armazenadas, consultadas e alteradas.

Modelo lógico

Faz o mapeamento dos dados da solução escolhida para a aplicação.

💡 Para lembrar: chave primária identifica um registro; chave estrangeira relaciona uma tabela com outra.
🔗Módulo 2 — Casos de Uso, DER e Modelo Lógico5 questões

Diagrama de Casos de Uso

Descreve requisitos funcionais de forma simples para usuários e desenvolvedores.

Atores

Representam os papéis e funções de cada participante dentro do contexto do sistema.

Relacionamentos

Podem ocorrer entre ator e caso de uso, entre atores e entre casos de uso.

DER

Modela os conceitos que devem ser armazenados em um banco de dados.

📌 Resumo: Casos de Uso → comportamento/requisitos. DER → dados que serão armazenados.
🐘Módulo 3 — PHP Básico5 questões

PHP

Linguagem de script que roda no servidor e processa os dados antes de retornar o resultado ao cliente.

Variáveis

São declaradas usando $, como $nome.

Tipos e operadores

O material destaca a resolução dinâmica de tipos. Operadores de atribuição: =, +=, /= e .=.

for

Repete determinado código um número conhecido de vezes.

Formulários

Dados enviados por POST podem ser recebidos com $_POST.

⚠️ Atenção: $_POST precisa receber dados enviados pelo formulário; executar o PHP diretamente sem POST pode gerar aviso de chave inexistente.
🧩Módulo 4 — Funções, POO e Sessões5 questões

Função

Bloco de instruções que realiza um procedimento e pode ser chamado quando necessário.

POO

O material destaca a redução de redundâncias e repetições como vantagem.

Classe

Estrutura que define tipos de dados, atributos e métodos de seus objetos.

Sessão

Recurso utilizado para manter informações salvas entre páginas.

session_start();
$_SESSION["nome"] = $_POST["nome"];
session_destroy();
🗄️Módulo 5 — MySQL, MySQLi e Atualização5 questões

Extensões

O material cita MySQL, MySQLi e PDO.

Reutilização de arquivos

include, include_once, require e require_once.

MySQLi

$conn = new mysqli(servidor, usuario, senha, banco_de_dados);

Consultas

$sql = "SELECT * FROM banco";

Atualização

O desafio trabalha com SELECT para buscar os dados atuais e UPDATE para gravar os dados alterados.

🌐Módulo 6 — SOAP e REST5 questões

SOAP

Protocolo robusto para troca de dados entre aplicações, baseado em XML e independente de linguagem e tecnologia.

RPC e cabeçalhos

O material apresenta chamadas de procedimentos remotos como recurso do SOAP. Reduzir ou eliminar elementos de cabeçalho pode melhorar o desempenho.

REST

Arquitetura apresentada como alternativa mais leve ao SOAP e sem estado (stateless).

VerboUso
GETRecuperação
POSTCriação
PUTAtualização/substituição
DELETEExclusão
📌 SOAP × REST: pense em SOAP como uma comunicação mais estruturada/robusta e REST como uma alternativa mais leve.
